# LAW 575 Internet Law · Spring 2027 · course site

The course page (index.html), the Unit Circles page (units.html), and the student documents as PDFs (docs/), served by GitHub Pages and framed in the Canvas course's front page.  A document keeps its file name across versions, so its address never changes;  the git history records what was posted when.  The Circle Guide is kept in the course's Google Drive folder instead, because it reprints casebook problems.  Course information only:  no student data lives here.  The pages are generated from the course masters (Course Anatomy and Unit Circles HTML) by the course kit;  edit the masters, not these files.
